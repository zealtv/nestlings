# Trial typed composition references

Use repository bootstrap and cross-repo examples to trial small, grep-friendly
references carried in ordinary Markdown, initially along these lines:

```text
glean:<finding-id>
lore:<item-id>
loom:<stitch-id>
path:<repo-relative-path>
```

Determine what, if anything, a Nest request needs for origin and reply routing.
Do not make transient, sweepable Nest items masquerade as durable records.

This stitch is an experiment, not authorization to make Nestlings own a
family-wide graph schema. Record what proved useful and recommend whether the
convention should remain in host policy, begin in Glean, or be extracted into a
separate family composition specification after multiple primitives consume it.

Done when the redesign examples use the convention consistently and its
ownership boundary is recorded.
