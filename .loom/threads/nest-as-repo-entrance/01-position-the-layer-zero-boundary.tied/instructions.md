# Position the layer-zero boundary

Revise the protocol's explanation and vocabulary so a nest is clearly the
entrance and transport layer for a folder, not only an inbox for an already
configured agent.

Make the distinctions explicit:

- a Nest item may be unclassified material rather than a shaped task;
- Nestlings owns safe intake and disposition, not project memory or planning;
- other primitives are optional destinations selected through tending;
- a repository may remain useful with only `.nest/` installed.

Keep the current mechanics generic and retain the principle that the filesystem
is the protocol. Record any terminology changes needed to make “nest,” “item,”
“tend,” and “hatch” work cleanly in both agent and repository contexts.

Done when the README states the new boundary without requiring knowledge of any
specific sibling primitive.
