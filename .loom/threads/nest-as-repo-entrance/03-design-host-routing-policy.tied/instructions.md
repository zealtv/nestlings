# Design the host routing policy

Turn `tend.md` into a useful host-local composition surface for a repository
nest. Provide a concise optional example that can classify an item after it is
read:

```text
unclassified arrival
  -> retain complete evidence
  -> distil current guidance
  -> create shaped work
  -> establish recurrence
  -> send to another repository
  -> hatch or drop
```

The example may name Lore, Glean, Loom, and Groundhog to show the family working
together, but those names must remain policy and documentation rather than core
Nestlings dependencies.

Keep `tend.md` operational rather than descriptive. Prevent it from becoming
project memory or a replacement for an agent instruction file.

Done when both a generic single-purpose nest and a repository-entry nest can use
the template without fighting its assumptions.
